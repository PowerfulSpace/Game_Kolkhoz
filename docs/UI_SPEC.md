# UI_SPEC.md — экраны и состояния «Колхоз»

Этот документ описывает **все экраны** приложения: layout, 
компоненты, состояния, поведение. Токены (цвета, размеры, 
типографика) — в `DESIGN_SYSTEM.md`. Продуктовая сторона — в 
`SPEC.md`.

**Правило:** если код в `app/ui/` расходится с этим документом — 
**документ прав**.

---

## 1. Общие принципы

### 1.1. Навигация

**5 экранов**, один `NavHost`:
HomeScreen ──► NewGameScreen ──► GameScreen ──► ResultScreen
│ │
│ ▼
└────────────────────────► HistoryScreen

text

**Переходы:**

- `HomeScreen` → `NewGameScreen` (кнопка «НОВАЯ ИГРА»).
- `HomeScreen` → `GameScreen` (кнопка «ПРОДОЛЖИТЬ ИГРУ», если есть 
  активная).
- `HomeScreen` → `HistoryScreen` (кнопка «ИСТОРИЯ ИГР»).
- `NewGameScreen` → `GameScreen` (после «НАЧАТЬ ИГРУ»).
- `GameScreen` → `HistoryScreen` (кнопка «ИСТОРИЯ»).
- `GameScreen` → `ResultScreen` (после «Завершить игру»).
- `ResultScreen` → `HomeScreen` (кнопка «НА ГЛАВНУЮ»).
- `ResultScreen` → `NewGameScreen` (кнопка «НОВАЯ ИГРА»).
- `HistoryScreen` → назад.

**Back-stack:** стандартный. С `GameScreen` — назад возвращает 
`HomeScreen` (не закрывает партию).

### 1.2. Ориентация

| Экран | Portrait | Landscape |
|-------|----------|-----------|
| HomeScreen | ✅ | ❌ (только portrait) |
| NewGameScreen | ✅ | ❌ |
| GameScreen | ✅ | ✅ |
| HistoryScreen | ✅ | ✅ |
| ResultScreen | ✅ | ❌ |

**Технически:** `MainActivity` — `screenOrientation="unspecified"`. 
Для `HomeScreen`, `NewGameScreen`, `ResultScreen` — **программно** 
блокируем portrait. Для `GameScreen` и `HistoryScreen` — 
разрешаем обе.

### 1.3. Общие состояния

Для **каждого** экрана предусмотрены:

- **Loading** — если данные загружаются.
- **Content** — основной.
- **Empty** — если данных нет (только `HistoryScreen`, 
  `HomeScreen` без активной партии).
- **Error** — если что-то сломалось.

## 3. NewGameScreen — Создание игры

### 3.1. Назначение

Настроить количество игроков (3–8), ввести имена, начать игру.

### 3.2. Layout (portrait)
┌─────────────────────────────────┐
│ ← НОВАЯ ИГРА │ ← топ-бар
│ │
│ СКОЛЬКО ИГРОКОВ? │ ← H2
│ │
│ ┌───────────────────────────┐ │
│ │ − 4 + │ │ ← PlayerCountSelector
│ └───────────────────────────┘ │
│ │
│ ОТ 3 ДО 8 ИГРОКОВ │ ← Caption
│ │
│ ИГРОКИ │ ← H2
│ │
│ ┌───────────────────────────┐ │
│ │ 1 [Саша ] × │ │ ← PlayerInput
│ └───────────────────────────┘ │
│ ┌───────────────────────────┐ │
│ │ 2 [Петя ] × │ │
│ └───────────────────────────┘ │
│ ┌───────────────────────────┐ │
│ │ 3 [Коля ] × │ │
│ └───────────────────────────┘ │
│ ┌───────────────────────────┐ │
│ │ 4 [Дима ] × │ │
│ └───────────────────────────┘ │
│ │
│ ┌───────────────────────────┐ │
│ │ НАЧАТЬ ИГРУ │ │ ← Primary
│ └───────────────────────────┘ │
└─────────────────────────────────┘

text

### 3.3. Компоненты

- **Топ-бар** — `KolhozTopBar` с кнопкой «назад».
- **`PlayerCountSelector`** — `− | N | +`, диапазон 3–8.
- **Список `PlayerInput`** — по количеству игроков.
- **`KolhozButton`** — «НАЧАТЬ ИГРУ».

### 3.4. Поведение

**Счётчик игроков:**

- Кнопка `−` уменьшает (минимум 3).
- Кнопка `+` увеличивает (максимум 8).
- При уменьшении — **удаляется** последний игрок.
- При увеличении — **добавляется** пустое поле.

**Ввод имени:**

- Поле ввода, `maxLength = 32`.
- **Номер** слева (`1`, `2`, ...).
- **Крестик** справа — удалить игрока (только если игроков 
  > 3).
- При удалении из **середины** — нумерация **сдвигается**.

**НАЧАТЬ ИГРУ:**

- Активна **только** если все имена валидны (не пустые, 
  уникальные, 1–32 символа).
- Иначе — **disabled**.
- При нажатии — создаём `Game` через `GameRules.createGame`.
- Если **есть активная партия** — сначала **диалог**: 
  «Завершить предыдущую?» → да/нет.
  - **Да** — `finishGame(previous)` + создать новую.
  - **Нет** — вернуться на `NewGameScreen`.

### 3.5. Состояния

**По умолчанию:** 4 игрока, все поля пустые, кнопка disabled.

**Валидация — inline:**

- **Пустое имя** — поле с красной границей, подсказка 
  «Введите имя игрока».
- **Дубликат** — поле с красной границей, подсказка 
  «Такое имя уже есть».
- **Длинное** — не даём ввести > 32 символов.
- Поле ввода ограничено maxLength=32 — длинное имя ввести 
  нельзя, ошибка по длине не показывается inline.

**Ошибка создания:**

- Если `GameRules.createGame` вернул `Failure` — показать 
  **snackbar** с текстом ошибки (человеческим).

### 3.6. Landscape

Не поддерживается. Программно блокируем portrait.

## 4. GameScreen — Игровой экран

### 4.1. Назначение

Главный экран. Показывает текущего игрока, счёт, кнопки удара.

### 4.2. Layout (portrait)
┌─────────────────────────────────┐
│ КОЛХОЗ ⋮ │ ← топ-бар
│ │
│ ХОДИТ │ ← Caption
│ │
│ САША │ ← PlayerName (32sp Bold)
│ +7 │ ← Display (52sp Bold)
│ │
│ ● ● ● ● │ ← SeriesIndicator
│ СЕРИЯ 4 │
│ │
│ ───────────────────────────── │ ← divider
│ │
│ Саша +7 │ ← PlayerRow
│ Петя +2 │
│ Коля −4 │
│ Дима −5 │
│ │
│ ───────────────────────────── │
│ │
│ ┌───────────────────────────┐ │
│ │ │ │
│ │ ЗАБИЛ │ │ ← Primary (64dp)
│ │ │ │
│ └───────────────────────────┘ │
│ │
│ ┌───────────────────────────┐ │
│ │ ПРОМАХ │ │ ← Secondary (56dp)
│ └───────────────────────────┘ │
│ │
│ ───────────────────────────── │
│ │
│ ↶ ОТМЕНА УДАРА ИСТОРИЯ │ ← bottom bar
└─────────────────────────────────┘

text

### 4.3. Компоненты

- **Топ-бар** — `KolhozTopBar` с `⋮` меню.
- **`CurrentPlayerCard`** — «ХОДИТ / ИМЯ / СЧЁТ / СЕРИЯ».
- **Список `PlayerRow`** — все игроки.
- **`KolhozButton`** — «ЗАБИЛ».
- **`KolhozSecondaryButton`** — «ПРОМАХ».
- **`KolhozBottomBar`** — «ОТМЕНА УДАРА», «ИСТОРИЯ».

### 4.4. Поведение

**ЗАБИЛ:**

1. Вызываем `GameRules.applyShot(game, currentPlayerId, POCKET, now)`.
2. Сохраняем через `repository.saveGame(newGame)`.
3. Обновляем `GameState`.
4. **Анимация** счёта: scale 1.0 → 1.12 → 1.0, 180ms.
5. **Не переходим** к следующему игроку.

**ПРОМАХ:**

1. Вызываем `GameRules.applyShot(game, currentPlayerId, MISS, now)`.
2. Сохраняем.
3. Обновляем `GameState`.
4. Ход переходит следующему.

**ОТМЕНА УДАРА:**

1. Вызываем `GameRules.undoLastShot(game)`.
2. Сохраняем.
3. Запоминаем `lastUndoneEvent`.
4. Показываем **snackbar**: «Удар отменён. [ВЕРНУТЬ]», 3 сек.
5. При нажатии «ВЕРНУТЬ» — `applyShot` с сохранённым event.

**ИСТОРИЯ:**

→ `HistoryScreen`.

**`⋮` меню:**
История
——
Завершить игру

text

- **История** → `HistoryScreen`.
- **Завершить игру** → диалог подтверждения → `ResultScreen`.

### 4.5. Состояния

**Игра активна:**

- Все кнопки активны.

**Игра завершена:** (не должно быть на этом экране — переходим 
на `ResultScreen`).

**Ошибка сохранения:**

- Показать **snackbar**: «Не удалось сохранить партию».

**Undo при пустой истории:**

- Кнопка «ОТМЕНА УДАРА» — **disabled**.

│ КОЛХОЗ ⋮ │
│ │
│ ИГРОКИ СЕЙЧАС БЬЁТ ДЕЙСТВИЕ │
│ │
│ Саша +7 САША ┌───────────┐ │
│ Петя +2 +7 │ ЗАБИЛ │ │
│ Коля −4 ●●●● └───────────┘ │
│ Дима −5 СЕРИЯ 4 │
│ ┌───────────┐ │
│ │ ПРОМАХ │ │
│ └───────────┘ │
│ │
│ ↶ ОТМЕНА УДАРА ИСТОРИЯ │
└───────────────────────────────────────────────────────┘

**Три колонки:**

- **Слева** — список игроков.
- **Центр** — текущий игрок + счёт + серия.

## 7. Навигация — детали

### 7.1. `NavHost`
"home" → HomeScreen
"new_game" → NewGameScreen
"game" → GameScreen
"history" → HistoryScreen
"result" → ResultScreen

text

### 7.2. Аргументы

- `GameScreen` — без аргументов (берёт активную партию).
- `HistoryScreen` — без аргументов (берёт активную партию).
- `ResultScreen` — `gameId` (завершённая партия).

### 7.3. Back-stack

- `HomeScreen` — корень.
- `NewGameScreen` → `GameScreen` — **не возвращаться** на 
  `NewGameScreen` (создание завершено).
- `GameScreen` → `ResultScreen` — **не возвращаться** на 
  `GameScreen` (партия завершена).
- `ResultScreen` → `HomeScreen` — **очистить** back-stack.

- ❌ Аватары / фото игроков.
